# Тестирование проекта

В данном файле приведены результаты тестирования программного средства для обнаружения мошеннических точек доступа в беспроводных Wi-Fi сетях.

Цель тестирования:
- проверить корректность работы алгоритма обнаружения мошеннических точек доступа;
- подтвердить соответствие программы заявленным функциональным требованиям;
- показать результаты работы приложения в контролируемых и реальных условиях.

## 1. Методология тестирования

Тестирование проводилось на устройствах с операционными системами:
- Windows
- Linux
- macOS

В ходе тестирования проверялись следующие функции:
1. Получение параметров текущей Wi-Fi сети.
2. Отображение параметров сети в интерфейсе программы.
3. Первичный анализ безопасности сети.
4. Определение производителя точки доступа по OUI.
5. Обнаружение подозрительных сетевых перенаправлений.
6. Мониторинг изменений параметров сети во времени.
7. Время обнаружения угрозы.
8. Реакция программы на угрозу.
9. Кроссплатформенность приложения.
