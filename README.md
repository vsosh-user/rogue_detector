Rogue AP Detector (PyQt)
========================
Приложение для мониторинга Wi‑Fi и предупреждения о возможных мошеннических точках доступа. Реализовано на Python + PyQt6.
Возможности
-----------
- Фиксирует параметры текущей подключенной сети (SSID, BSSID, канал, шифрование).
- Регулярно проверяет статические параметры: смена SSID/BSSID/канала/шифрования вызывает предупреждение.
- Отслеживает резкие скачки сигнала (увеличение/падение) как индикатор возможной подмены.
- Всплывающие предупреждения с указанием изменившихся параметров.
- Проверяет производителя точки доступа по OUI (BSSID) — используется локальный список доверенных вендоров из `rogue_detector/data/oui_whitelist.txt` (можно расширять).
- Показывает диапазон (2.4/5/6 ГГц) и скорости приёма/передачи для подключённой сети (если поддерживает платформа).
- Поддержка macOS (`airport`/`system_profiler` для BSSID), Linux (`nmcli`/`iw`) и Windows (`netsh`), UI на PyQt6.
Установка
---------
1. Установите Python 3.10+.
2. Установите зависимости:
   ```bash
   python3 -m pip install -r requirements.txt
   ```
3. Запустите:
   ```bash
   python3 main.py
   ```
Важно для Windows
-----------------
- На Windows программу лучше запускать с правами администратора.
- Это нужно для того, чтобы приложение могло не только обнаружить подозрительную точку доступа, но и разорвать подключение или отключить Wi‑Fi адаптер после обнаружения угрозы.
- Без прав администратора обнаружение сети обычно работает, но отключение Wi‑Fi может не сработать.

Как запустить от имени администратора:
1. Откройте меню `Пуск`.
2. Найдите `Командную строку` (`cmd`) или `PowerShell`.
3. Нажмите правой кнопкой мыши.
4. Выберите `Запуск от имени администратора`.
5. Перейдите в папку с проектом:
   ```bat
   cd /d "C:\путь\к\папке\проекта"
   ```
6. Запустите программу:
   ```bat
   python main.py
   ```


Как работает детекция
---------------------
- При первом получении всех параметров подключенной сети baseline фиксируется автоматически.
- Каждое сканирование (раз в `n`, по умолчанию 6 с) проверяет подключенную сеть:
  - сравнение SSID/BSSID/канала/шифрования с baseline и с предыдущим измерением;
  - скачок уровня сигнала |Δ| > (15 дБ по умолчанию) трактуется как риск;
  - пред-проверка: открытая/WEP сеть → критично; LAA BSSID или неизвестный OUI → предупреждение; если клиент умеет WPA3, а сеть не WPA3 — предупреждение (возможный даунгрейд).
  - сверка производителя BSSID с производителем шлюза (OUI): если различаются и не из списка доверенных вендоров — предупреждение.
- При срабатывании — запись в уведомления, всплывающее окно с изменившимися параметрами, разрыв соединения.
Интерфейс
---------
- Карточка текущей сети с ключевыми параметрами.
- Таблица доступных сетей с подсветкой подключенной, выделением открытых сетей.
- Список уведомлений и всплывающие предупреждения.
Настройка и файлы
-----------------
- Список доверенных OUI: `rogue_detector/data/oui_whitelist.txt` (один префикс aa:bb:cc на строку). Можно пополнить проверенными вендорами (Megafon/Beeline/MTS используют Sagemcom, Sercomm, Huawei, ZTE и т.д.).
- Параметры сканирования и пороги — `rogue_detector/models.py::DetectionConfig`.
- UI и логика мониторинга — `rogue_detector/app.py`.
- Сканирование платформ — `rogue_detector/platform_scanner.py` (band/rate/BSSID доп. парсинг под macOS/Linux/Windows).
